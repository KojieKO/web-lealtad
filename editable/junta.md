# Junta de Gobierno

Este es el único archivo que hay que modificar para añadir, quitar o cambiar miembros de la Junta de Gobierno.

- Añade cada persona como una fila de la tabla.
- Conserva las dos columnas: `Cargo` y `Nombre`.
- Si un cargo se repite, escribe una fila por cada persona.
- Al subir el cambio a GitHub, `hermandad.html` se actualiza automáticamente.
